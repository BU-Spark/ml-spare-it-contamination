Several notebooks are run with the Spare-it dataset on SCC, so the file paths are specific to the SCC file system. To use the notebooks, ensure that you set the appropriate paths to the dataset containing all your images and labels data. You will also need to install the packages we use from the requirements.txt file:

```
pip install -r requirements.txt
```
